# Shared asset rules

Applies to both Codex and Claude Code. Read `assets/README.md` and `assets/references/index.json` before adding/preparing art. Store original files under `references`, editable working files under `source`, and prepared game textures under `game`. Preserve originals and update the index in the same commit when availability changes. Record frame/tile/pivot details for prepared textures and distinguish stored, prepared and integrated status. Check the shared coordination board and remote branches before overlapping edits.
