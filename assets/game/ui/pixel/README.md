# Pixel UI pieces (M13)

Sliced from Dogobongocat's **UI assets pack** (https://dogobongocat.itch.io/ui-assets-pack-srt,
license **CC0 1.0**; source sheets in `assets/source/packs/dogobongocat_ui/`) by
`tools/prepare_pixel_ui.py`. Used as nine-patches by `scripts/ui/pixel_box.gd` through
`scripts/ui/ui_style.gd` (`UI.piece(kind)`): navy panels, parchment, plates, gold-cornered slots,
bars, the portrait ring and the day/night clock faces. Nearest filtering, 1:1 with the 640x360
viewport.
