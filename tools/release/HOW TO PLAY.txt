TempestRPG - playing together
=============================

Everyone: unzip and run TempestRPG.exe (no installation). Windows may warn about an unknown
app the first time: "More info" -> "Run anyway". Allow it through the firewall when asked.

EASIEST: JOIN CODES (no router settings, nothing to install)
  Host:   start a world (Continue / New Game) -> Esc -> "Invite with a code" -> "New invite code"
          -> "Copy code" and send it to ONE friend (Discord, chat...).
  Friend: TempestRPG.exe -> "Join a Friend" -> paste the code -> "Join".
          The game shows a REPLY code -> copy it and send it back to the host.
  Host:   paste the reply code -> "Let them in". Repeat with a new code for each friend.
  Codes contain your Internet address: share them only with friends. Some strict networks
  (mobile hotspots, school/company networks) can block join codes.

SAME HOME NETWORK
  Host: Esc -> "Open to friends". Friends: "Join a Friend" -> the 192.168... address shown.

SERVER WINDOW (optional; the world runs while you are not playing; needs port sharing for
friends outside your network: UDP 24560, e.g. FRITZ!Box -> Internet -> Permit Access)
  1. Double-click "Start server.bat" (hosts your most recently played world).
  2. You: TempestRPG.exe -> Join a Friend -> 127.0.0.1  (you play your own character)
  3. Friends: Join a Friend -> the address the server window shows.

HANDY
  Your saves are in %APPDATA%\TempestRPG (type it into the Explorer address bar).
  Esc -> Options: HUD size (65-100%), window size, sound.  F1: hide/show the controls line.
